# Forgotten Island Memory Match

A small phone-landscape browser game where players match memory charms to advance the story video.

## Play locally

Open `index.html` in a browser, or run a local static server:

```sh
python3 -m http.server 8766
```

Then visit `http://127.0.0.1:8766/index.html`.

## Included assets

The repository includes the final game files, the background story video, the poster image, and the exact matched item sprites used in gameplay.
